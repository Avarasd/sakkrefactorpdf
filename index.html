int check_eval(char board[8][8]) {
    int eval = 0;
    for(int i = 0; i < 8; i++) {
        for(int j = 0; j < 8; j++) {
            char piece = board[i][j];
            if(piece == '.') continue;

            int value = 0;
            bool isWhite = false;
            if(piece > 'Z'){
                isWhite = true;
                piece -= SMALL_CAP_DISTANCE;
            } else {
                isWhite = false;
            }

            switch(piece){
                case 'Q': value = VAL_QUEEN; break;
                case 'R': value = VAL_ROOK; break;
                case 'N': value = VAL_KNIGHT; break;
                case 'B': value = VAL_BISHOP; break;
                case 'P': value = VAL_PAWN; break;
                case 'K': value = VAL_KING; break;
                default: value = 0; break;
            }

            if(isWhite) eval += value;
            else eval -= value;
        }
    }
    return eval;
}

int check_eval(Piece *board[8][8]) {
    int eval = 0;
    for (int r = 0; r < 8; r++)
        for (int c = 0; c < 8; c++) {
            Piece *p = board[r][c];
            if (p == nullptr) continue;
            eval += isWhitePiece(p) ? p->value() : -p->value();
        }
    return eval;
}
Polymorphic Valuation Win
Encapsulated Values: Replaced 15 lines of monolithic switch-case with a single p->value() call. Replaced ASCII arithmetic with type-safe nullptr checking.
Key Improvements & Architecture

Replaced 32 lines of procedural code with 10 lines of clean OOP. The C version used manual ASCII offset arithmetic (piece > 'Z') and a bulky 15-line switch statement to map characters to values. In C++, each piece encapsulates its own material value through polymorphism (p->value()), guarded by type-safe nullptr checks instead of magic character comparisons.

    Piece movPiece;
    bool Piece_found = false;

        if(move.figure == Pieces[i]->figure){
            movPiece = *Pieces[i];

    Distances d;

    switch(movPiece.figure){
        case 'P': return is_pawn_valid(move, position, d, en_passant_col);
        case 'N': return is_knight_valid(move, position, d);
        case 'K': return is_king_valid(move, position, d);
        case 'R': return is_rook_valid(move, position, d);
        case 'B': return is_bishop_valid(move, position, d);
        case 'Q': return is_rook_valid(move, position, d)
               || is_bishop_valid(move, position, d);
        default: return false;
    }
}

OCP & Direct Dispatch Win
Open-Closed Principle: Adding a new piece requires zero modifications to this dispatch engine. Direct O(1) pointer dereferencing completely replaces global arrays and linear loops.
Key Improvements & Architecture

Cut from 34 lines down to just 5 lines (-85%). In C, move validation required searching an O(N) global piece array, instantiating an intermediate distance struct, and routing through a rigid procedural switch. C++ replaces all of this with direct O(1) board lookup and dynamic polymorphism (p->isValidMove(...)), adhering strictly to the Open-Closed Principle where new pieces can be added with zero changes to existing dispatch code.

void BoardTree::load(const char *filename) {
    std::ifstream in(filename, std::ios::binary);
    if (!in)
        throw FileNotFoundException(filename);
    BoardElement element;
    while (in.read(reinterpret_cast<char *>(&element), sizeof(element)))
        createFromElement(&element);
}
RAII & Exceptions
Deterministic Cleanup: std::ifstream automatically releases OS file handles on scope exit or exceptions. Replaces silent failures with explicit typed errors.
Key Improvements & Architecture

Replaced raw FILE* handles and double pointers (Board** head) with an encapsulated BoardTree::load class method. In C, manual fopen/fclose leaves file descriptors vulnerable to leaks on early exits, while failing silently on missing files. C++ leverages deterministic RAII via std::ifstream to guarantee automatic cleanup on scope exit, paired with explicit FileNotFoundException error handling.
